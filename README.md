# YubiKey AAGUIDs
_This repository hosts a 🌐[webpage](https://JMarkstrom.github.io/aaguids/) to search, filter and export YubiKey AAGUIDs._    

**Note**: CSPN YubiKeys have been excluded since AAGUID overlaps with standard models.
